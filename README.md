# 墨間 SUMI Reader

跨手機、平板、桌面瀏覽器的靜態漫畫閱讀器。繁體中文介面，沒有廣告、追蹤器、帳號、後端或外部資源依賴。

## 使用

1. 解壓縮並保持檔案結構完整。
2. 桌面瀏覽器直接開啟 `index.html`。原創短篇、排行榜與本機圖片匯入皆不需要伺服器。
3. 若要讓手機／平板從網址使用，須將此資料夾放在獲准的靜態 HTTPS 主機。此交付本身沒有公開發布；iOS「檔案」預覽不是完整瀏覽器，可能不執行 JavaScript。

這是響應式 Web app，不是已上架的原生 App，也沒有宣稱取得原生平台認證。首次載入後所有程式與示例皆為本機檔案；沒有 Service Worker、背景網路更新或遠端漫畫下載。瀏覽器儲存政策可能限制直接開啟檔案時的進度儲存。

## 閱讀

- 首頁「開始閱讀原創短篇」：六頁、兩話的原創 SVG 漫畫《雨後書店》。
- 單頁／長條、章節／頁碼跳轉、50–200% 縮放、右至左／左至右。
- 左右方向鍵（避開下拉選單）、Home / End、Esc 返回；Tab 可操作所有控制。
- 單頁以左右滑動翻頁。右至左時向右滑或左方向鍵是下一頁。放大後拖曳捲動，避免與翻頁衝突。
- 長條模式上下捲動；離開後保留頁碼。收藏與進度存在 localStorage，僅限該瀏覽器。
- 匯入 JPG / PNG / WebP，依檔名自然排序（1、2、10）。最多 100 張，每張 12 MiB、合計 160 MiB；單張 40 MP、合計 160 MP。先檢查檔頭、尺寸，再解碼。
- 不接受 SVG / PDF / ZIP / CBZ。避免 ZIP 解壓縮、安全與行動記憶體風險，這一版沒有宣稱支援 CBZ。
- 匯入檔案不離開裝置，不儲存原始圖片；關閉閱讀器、重新整理後須重新選取檔案。選取相同檔案組合可恢復頁碼。

## 開發與測試

無編譯步驟、無執行期套件。`core.js` 提供可單獨測試的排序、檔案檢查、圖片尺寸、儲存資料驗證函式。

測試與限制見 `QA.md`。在需要安裝 jsdom 的環境，可由官方 npm 套件取得開發測試依賴；不影響終端使用者離線使用。`create-art.py` 是生成原創 SVG 的可重現來源，不是執行 app 的必要條件。
